Azure Container Registry — Arquitectura y Tiers

Azure Container Registry (ACR) es el registro privado de imágenes de contenedor en Azure, base para despliegues en AKS, App Service y Container Apps. Conoce sus tiers para seleccionar el adecuado según escenarios de desarrollo, producción y alta disponibilidad. Lee las señales: geo-replicación, Private Endpoint y digest suelen decidir más que el nombre del SKU.
? PREGUNTA GUÍA:¿Cuál tier de ACR es adecuado para producción con geo-replicación y private endpoints?
⚠ Trampas del examen
1
Basic es suficiente para producción
→
Basic carece de Private Endpoints y geo-replicación. Para producción con seguridad de red y HA global se requiere Premium.
2
La tag :latest siempre es segura e inmutable
→
La tag :latest es mutable — puede apuntar a imágenes distintas en cada push. Usa el digest SHA256 para referencias inmutables.
3
Geo-replication y zone redundancy son equivalentes
→
Geo-replication replica entre regiones (latencia global). Zone redundancy protege contra fallas de zonas dentro de una región. Son independientes y complementarios.
